    How this page updates

    1. npm run week -- w01 creates the week's folder from the template.
    2. Design ticks when design.md no longer has its todo line.
    3. Build ticks when src/ has code in it.
    4. Break it ticks when break-it.md no longer has its todo line. Its "What broke" line shows here.
    5. Publish ticks when post/index.md says published: true.
    6. Push to GitHub and the page rebuilds. Locally, run npm run tracker and refresh.
    Check-ins run every Saturday at 15:00 and read this repo. After the move in mid-January they switch to India time.
